# BMGenie CRM — API

Express + SQLite backend for BMGenie CRM.

- **Frontend (Vercel):** https://github.com/Bmgenieai/BMG-CRM
- **This repo:** API only — run on Windows / Node host (`npm start`, default port `4050`)

```bash
cp .env.example .env
npm install
npm run seed   # first time
npm start
```

Health: `GET /api/health`
